Workspace MCP（個人利用ツール）

このページは、芥川幸之助が自分のGoogleアカウント（Gmail・Google Drive・Google スプレッドシート等）を、自分のパソコン上のAIアシスタントから利用するための個人用ツール「Workspace MCP」に関する説明ページです。第三者向けのサービスではありません。

プライバシーポリシー

  • 本ツールは、開発者本人（芥川幸之助）のみが、本人のGoogleアカウントに対して使用します。
  • 取得したデータ（メール、ファイル、スプレッドシート等）は本人のパソコン内でのみ処理され、第三者に提供・販売・共有することはありません。
  • 本ツールは第三者のユーザー登録・データ収集を行いません。
  • Google APIから取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。
  • お問い合わせ: shotaro5.6.8@gmail.com

Privacy Policy (English)

"Workspace MCP" is a personal tool used only by the developer (Konosuke Akutagawa) to access his own Google account from an AI assistant running on his own computer. It is not a service for third parties.

  • Data retrieved from Google (emails, files, spreadsheets, etc.) is processed only on the developer's own computer and is never provided, sold, or shared with any third party.
  • This tool does not register third-party users and does not collect data from anyone else.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
